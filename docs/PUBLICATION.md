# 公開する範囲と確認事項

このキットは、一般的な文書作成・作図の手順と模式図を公開するための構成です。
入力資料、作成した成果物、利用環境の設定は、配布するキットの外で管理します。
配布するSkillは `layered-docs` と `drawio-diagrams` の2つです。
計画管理・タスクの終了判定を行うSkillは収録しません。

## リポジトリには配布対象だけを置く

公開するのは、このキットの配布フォルダ内のファイルです。
作業用フォルダ、過去の移行パック、個人のホーム、既存の業務リポジトリを、そのまま公開元にしないでください。
現在のファイルだけでなく、公開するGit履歴にも非公開の内容が入っていないことを確認します。

| 確認する対象 | このキットでの扱い |
|---|---|
| 個人名、案件名、実際の接続先、認証値、環境固有のパス | 収録対象にしない |
| 既存案件の図、スクリーンショット、ログ、実データ | 収録対象にしない。図は一般的な模式図を使う |
| ベンダーや第三者が配布するSkill、コード、画像 | コピーして再配布せず、環境側で用意する |
| 個人の共通指示、ツール設定、実行権限 | コピーせず、一般的な指示例だけを置く |
| インストーラ、フック、CI、外部接続処理 | 同梱しない |
| 入力資料と生成した文書・図 | 配布元へ混ぜない。個別の公開可否を確認する |

`.gitignore` は混入しやすいファイルの一部を除外する補助です。
任意の名前で保存した機密や、すでに記録されたGit履歴を検出・削除する仕組みではありません。

draw.ioファイルは、表示されるラベルだけでなく、XMLの全属性、非表示レイヤー、注釈、埋め込みデータも確認します。
Gitの作者名、メール欄、日時はファイル本体とは別の情報です。
公開する場合はこれらも確認し、実メールアドレスの公開を避けるならGitHubのnoreplyアドレス等を使います。
一般的な内容だけを配布することと、作者を匿名にすることは別です。

## ライセンスは適用できる範囲に限る

このキットの文章とテンプレートにはCC0 1.0 Universalを指定し、条件全文を同梱します。
追加する素材に別の権利者がいる場合は、その素材の公開・再配布条件を確認してください。
CC0の指定によって、第三者の権利や、所属組織の公開権限が自動的に解決するわけではありません。
根拠は [CC0の公式条件](https://creativecommons.org/publicdomain/zero/1.0/legalcode.en) で確認できます。

## 導入先の指示と権限を維持する

導入例は、既存の共通指示へ必要な部分だけを統合するための例です。
共通指示を全置換したり、認証や権限を変更したりする必要はありません。
同名Skillの既存配置と、指示ファイルを新設した場合の読込順も確認します。

SkillはAIが読む指示であり、実行権限を強制的に制限する機構ではありません。
読み込んだ後にAIが行う操作は、利用者の依頼と、実行環境の権限に従います。

## 品質の確認範囲を示す

XMLの整合、文書の根拠、実ファイルの描画は、それぞれ別の確認です。
公開資料に互換性や検証結果を書く場合は、実際に確認した環境と範囲だけを記載します。
キットを公開できることと、特定組織への持ち込みや特定資料の外部送信が許可されることも別の判断です。
