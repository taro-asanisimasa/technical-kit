# 出力形式に合わせて成果物を確認する

この参照は、文章を編集用文書、配布用ファイル、スライドとして作成・更新するときに使う。
文章の確認に加えて、提出するファイルが用途を満たすかを確かめる。

## 用途と利用できる出力機能を確かめる

希望する形式、提出先での読み方、後から編集する必要がある部分を確認する。
既存の出力・編集・変換・描画機能を調べ、今回の形式を扱えるものを使う。
特定のアプリ、接続先、外部の保存領域が利用できるとは仮定しない。
別の形式で代用する場合は、依頼された形式との違いと、維持できない機能を説明する。

| 形式や用途 | 確認する性質 |
|---|---|
| 編集用文書 | 見出し、段落、表が必要な単位で編集できること |
| 固定したレイアウトで配布する文書 | ページの順番、改ページ、文字や図表の見え方が意図どおりであること |
| スライド | 投影や閲覧の大きさで、情報の順序と図表を読み取れること |
| 複数形式での提出 | 見出し、表、数値、図、注記の内容が形式間で一致すること |

## 編集用の構造を残す

編集が必要な表は、画像に置き換えず、行・列・セルを扱える構造で作る。
編集用として提出する場合は、保存したファイルでもその構造が残っているかを確認する。
見た目を整える処理によって、文字や図表を後から変更できなくしていないかを確かめる。

表の見出しと値の対応、数値の桁や単位、注記の参照先を、変換後のファイルでも保つ。
画像としてしか出力できない場合は、見た目の確認と編集可能性の確認を分け、編集上の制約を報告する。

## 提出するファイルそのものを描画する

生成に使った原稿の表示だけで確認を済ませず、保存・変換した最終ファイルを描画する。
利用できる閲覧機能やページ画像を使い、ページやスライドを順に確認する。

- 文字の欠落、置換、切れ、読みにくい大きさがないか。
- 表の列、繰り返す見出し、改ページで対応関係が崩れていないか。
- 図、線、凡例、注記が重ならず、本文と同じ内容を示すか。
- 見出しから本文への順序と、余白やページ分割が読み方を妨げていないか。

見た目を修正したら、修正後の提出ファイルで影響箇所を再確認する。
描画手段がない場合は、文字や構造について確かめた範囲を示し、表示確認は未実施として残す。

## 保存した状態から続けられるようにする

提出ファイルと、再編集に必要な元データの関係を明らかにする。
保存した編集元を開き直し、必要な文章や表を変更できる状態かを確認する。
変換後の提出物だけを残すと再編集できない場合は、その制約と編集元の所在を引き継ぐ。

作業を中断する場合は、作成済みのファイル、最後に確認した範囲、残った修正を短く残す。
確認を予定しているだけの項目を、確認済みの結果として記録しない。
